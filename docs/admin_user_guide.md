# Administrator User Guide
## Operating the Market Intelligence & Information Aggregation Platform

---

### 1. Dashboard Overview
Upon logging in at `https://yourdomain.com/`, the **Overview** page provides a live executive summary:
- **Connected Sources**: Real-time count of active vs. paused sources.
- **Total Intelligence Collected**: All items aggregated from Telegram, Facebook, LinkedIn, Portals, and RSS feeds.
- **Awaiting Approval**: Count of freshly ingested items analyzed and scored by AI ready for editorial review.
- **Duplicates Filtered**: Reposts and cross-platform copies clustered into `DuplicateGroups` with saved LLM costs.
- **Cron Sync Activity**: Historical log of recent cPanel batch execution runs.

---

### 2. Managing Information Sources
Navigate to **Sources** (`/sources/`):

#### Adding a Telegram Channel or Group:
1. Click **+ Add Information Source**.
2. Select **Telegram Connector**.
3. Set **Source Type**: Channel or Group.
4. Set **Endpoint URL**: `@channel_username` (e.g. `@ethio_tenders_alerts`).
5. Choose collection frequency (e.g. 15 minutes) and priority (1-5).
6. Click **Save Source**.

#### Adding a Facebook Page:
1. Select **Meta Facebook Connector**.
2. Set **Endpoint**: Numeric Page ID or Page handle.
3. Ensure Connected Account has a valid Page Access Token with `pages_read_engagement`.

#### Adding an RSS Feed or Website Portal:
1. Select **Universal Web Crawler** or **RSS Ingestion**.
2. Set **Endpoint**: Feed XML URL (e.g. `https://example.com/feed.xml`) or HTML URL.
3. For custom HTML scraping, add CSS selectors in the source configuration JSON.

---

### 3. Reviewing Intelligence & Editorial Curation
Navigate to **Intelligence** (`/items/`):
- Filter by **Category** (Tenders & Procurement, Healthcare, Pharma, Medical Devices, Jobs, Business News).
- Filter by **Status** (Pending Review, Approved, Published, Rejected, Duplicate).
- **High-Efficiency Bulk Actions**:
  - Select individual rows or use the master "Select All" checkbox in the header.
  - Execute **Bulk Approve** (approves items and dispatches push alerts to configured channels).
  - Execute **Bulk Publish & Alert** (broadcasts to external webhooks and Telegram alert bot).
  - Execute **Bulk Reject** or **Archive** for swift triaging of large batches.
- Click **Review →** on any item to open the detailed inspector:
  - View **Executive Summary** and **Detailed Findings** generated by Google Gemini.
  - View **Commercial Implications** and Amharic translation if detected.
  - Inspect structured business entities: Organization, Contact Phones, Email, Budget, Deadlines.
  - Review **Matching Duplicate Cross-Posts** from other channels.
  - One-click actions:
    - **Approve**: Marks item as verified business intelligence and triggers outbound alerts.
    - **Publish Now**: Syndicates item to active webhooks and consumer APIs.
    - **Reject**: Discards unwanted or low-relevance content.
    - **Re-Analyze with AI**: Forces a fresh Gemini AI analysis pass.

---

### 4. Publishing & Push Alerts
Navigate to **Publishing** (`/publishing/`):
- **Outbound Telegram Push Alerts**:
  - Instant alerts for high-relevance intelligence (&ge; 75% score threshold by default).
  - Previews contain formatted Markdown with Organization, Reference Number, Financials (Budget, Bid Bond, Salary), and Deadlines.
  - One-click **Send Test Alert** to verify bot connectivity and chat ID configuration.
- **Webhook Syndication**:
  - Register external webhook endpoints to receive real-time JSON payloads when items are approved.
  - All webhooks include `X-Hub-Signature-256` HMAC signatures for end-to-end security.

---

### 5. AI Spend Controls & Circuit Breaker
Navigate to **AI Engine** (`/ai-settings/`):
- Monitor today's LLM API calls against daily quota (`AI_DAILY_MAX_CALLS`, default: 500).
- Monitor token volume (input vs. output) and real-time dollar consumption (`AI_DAILY_SPEND_LIMIT_USD`, default: $2.00/day).
- **Automated Circuit Breaker**: If spend or call thresholds are breached, the system automatically trips the breaker and routes all subsequent item extraction to the local semantic heuristic parser—guaranteeing 0 unexpected cost overruns.

---

### 6. Authentication & Session Security
- Strict administrative authentication via `/login/` with Django session protection and CSRF validation.
- All dashboard views enforce `@login_required(login_url='login')`.
- Authenticated user badge and secure `/logout/` action displayed in the top header.

---

### 7. System Health & Diagnostics
Navigate to **System Health** (`/health-status/`):
- Inspect cPanel cron distributed locks (`DatabaseLock`).
- Verify available server disk space and local media writeability.
- View exact cron job command syntax for your cPanel server.
